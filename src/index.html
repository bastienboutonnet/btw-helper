    Logic: classification follows Expense Tax Name 1. Rows named Reverse Charge → net + computed VAT into 4a (non-EU) or 4b (EU) by country, and the same VAT into 5b. Vendor country is taken from your saved map, else detected inside the vendor name (e.g. brackets or after a dash like Acme – DE), else you set it in the table. Non-EUR rows use the Converted Amount when present, otherwise Amount × Exchange Rate. Nothing is filed automatically — this only computes the numbers you type into Mijn Belastingdienst.
